# Déjà Lu

프랑스어를 글자 이름(아베세데)이 아니라 **소리 덩어리**로 읽는 입문용 웹앱.
Déjà Lu는 프랑스어로 "이미 읽었다"는 뜻이다. 처음 보는 단어도 이미 읽은 것처럼 읽히게 하는 것이 목표다.

🌐 https://sidebatch.github.io/deja-lu/

## 왜 소리 덩어리인가

A, B, C는 글자 목록일 뿐, 단어를 읽게 하지 않는다.
eau, ou, on처럼 글자 여러 개가 소리 하나로 붙는 덩어리를 하나의 알파벳처럼 다뤄야
단어가 보이기 시작하고 읽는 속도가 붙는다.

## 콘텐츠 현황

- 소리 덩어리 18종: OU · ON/OM · EAU · AU · AN/AM · EN/EM · AIN/EIN/AIM/IN/IM · UN/UM · OI · OIN · AI/EI · EU · U · CH · GN · ILL · TION · É/ER/EZ
- 덩어리별 예시 단어 총 100개 (덩어리 부분만 빨간색 표시)
- 문장 예시 5개 (문장 안에서도 덩어리만 빨간색 표시)
- 읽지 않는 끝글자 섹션: 끝 P/T/D · 끝 S/X (안 읽음, 회색 표시), 끝 C/R/F/L (읽음, 빨간색 표시), 끝 E (앞 자음을 살리는 쌍 비교) — 단어 29개

## 기능

- 단어 탭: 미리 생성한 프랑스어 음성(MP3, 페이지 내장)으로 재생 — 기기 TTS에 기대지 않아 폰에서도 재생된다
- 연습 모드: 빨간 표시를 끄고, 단어를 누르면 그 단어만 표시가 돌아오며 소리도 난다
- PWA: 홈 화면에 설치 가능, 오프라인 동작
- 방문 통계: GoatCounter (대시보드 https://deja-lu.goatcounter.com, 쿠키 없음)

## 발음 표기에 대해

한국어 발음 표기는 전부 대략적인 길잡이다. 딱 맞는 한국어 소리가 없는 경우가 많고,
애매한 소리는 하나로 단정하지 않고 범위로 표기한다.
예: IN/OIN은 "앵~앙 사이", UN은 "엉~앵 사이 (사람마다 다름)", AI는 "에~애 사이".
정확한 소리는 단어 음성을 들어서 잡는 것이 원칙이다.
