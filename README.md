# Déjà Lu

프랑스어를 글자 이름(아베세데)이 아니라 **소리 덩어리**로 읽는 입문용 웹앱.

eau, ou, on, ain/ein/aim/in/im 같은 덩어리를 하나의 알파벳처럼 다루고,
덩어리가 들어간 단어를 빨간색 표시와 함께 보여준다.
단어 음성은 기기 TTS가 아니라 미리 생성한 프랑스어 MP3를 내장해 폰에서도 재생된다.

- 주소: https://sidebatch.github.io/deja-lu/
- 구성: 단일 index.html + PWA (manifest, service worker, icons)
- 콘텐츠: 소리 덩어리 18종, 단어 100개, 문장 5개
- 한국어 발음 표기는 전부 대략적인 길잡이이며, 애매한 소리는 범위로 표기한다.
